# Historical processing tools

These original project scripts are retained for traceability. They describe the 3MF inspection, reporting, geometry registration and catalog extraction work used during development.

They are **not a supported one-command asset builder**. Their local paths have been replaced by placeholders, and their original intermediate inputs, model assets and upstream data are not distributed. Some require NumPy, Trimesh, SciPy, Pillow or platform-specific fonts. Read and adapt them before use; the current production entry point is the repository root, not this folder.

No upstream robot meshes, URDF files, full source parameter dumps, model renderings or upstream catalog tables are included. See `THIRD_PARTY_NOTICES.md` and `docs/local-assets.md`.
