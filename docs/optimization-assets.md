# 个人版资源加载与缓存优化（2026-10-24）

范围：`codex/optimization-assets`，基线 `0699ccf96b7b101a57ab4cfb2754983f0d512a9a`。只修改本任务独占工作树；未切换正式服务、修改生产资产、个人数据库、布局或教程翻译。

## 实现

- 资产准备：Python 默认导入生成 DDG1；可用 `--positions` 在有 Node / `npm ci` 的准备机器生成 POS1。启动用户仍只需 Python 3.9 标准库。两个生成器最后原子写入本地完整性清单；重新生成 DDG1 时移除旧 POS1。POS1 生成前验证 DDG1 与当前模型、原始网格、清单相符。
- 个人版提供压缩包前核对模型、原始网格和包的 SHA-256；缺失、损坏或旧版本拒绝提供，前端沿现有 POS1 → DDG1 → raw 路径回退。DDG1 解码器新增长度/流边界检查，截断数据不再静默补零。
- 静态文件采用基于内容的 ETag、`no-cache`、`Vary: Accept-Encoding` 与 gzip。条件请求可返回 304。模型、代码、全部语言表及组装网格均每次验证，不依赖 mtime 秒精度或长期过期时间。API/方案/导出继续 `no-store`，包括复用同一 HTTP 连接时。媒体保留 Range 读取。
- 保留 12 语言表及同步切换接口；通过压缩和条件请求减少其重复传输，未为拆语言包改变同步翻译接口或英文 fallback。
- 音乐/提示音改为按需赋予资源地址、`preload=none`；隐藏页和浏览器尚未允许播放时不下载整首音乐。首次有效用户操作后仍调用原生播放并沿用淡入、循环和切页暂停。

本地生成数据：DDG1 2,310,694 B；POS1 869,922 B（253,834 个三角形、66 个网格）；POS1 gzip sidecar 640,279 B。个人 HTTP 的 gzip 等级不同，实际传输大小以浏览器证据为准。资产和完整性清单均忽略，不推送模型或衍生资产。

## 2026-10-24 后续定位与修复

主控要求在同一分支继续定位首轮 ready 回退与首次组装尾延迟；本节是当前结论，首轮测量保留作原始证据。

已确认并修复两项服务端回归：

1. **304 前重复压缩。** 初版为计算 gzip 的 ETag，在检查条件请求前先压缩。24 项缓存被约百个资源挤出后，每次加载 4.6 MB 组装网格都再次执行 gzip，单次约 230 ms。修复为先用当前内容/表示生成验证器，304 直接返回。动态 gzip 使用弱 ETag，准备好的 gzip 使用其实际内容 SHA-256；不同平台 gzip 头部不会错误地共用强验证器。回归测试实际得到 304，并断言压缩器调用为零。
2. **冷请求现场压缩大网格。** 默认模型/组装导入及 POS1 生成现在准备 `.gz` 与 `.gzip.json`；已有本地资产可运行 `python3 scripts/prepare_delivery.py assets`。服务端读取预压缩文件前检查原始内容 SHA-256 和 gzip SHA-256。坏 gzip 或旧原始内容不会使用旧副本，仍有动态 gzip fallback。系统启动只需 Python 3.9，准备过程也只用标准库（POS1 自身仍是已有的 Node 准备工具）。在准备后的样本中，模型/组装资源动态压缩调用为零。

诊断工具仅在 tests 中临时包裹服务和浏览器 API，没有给真实产品增加测试接口或更改预热/页面切换。`tests/resource_diagnostic_server.py` 记录请求总时长、压缩和完整性校验耗时；`tests/resource-diagnostic-browser.js` 分开记录激活提交、两帧等待、启动长任务、超过 3 ms 的同步 WebGL 调用及音乐赋址/播放调用。所有有埋点版本使用同样工具比较。

### 首次激活尾延迟的边界

历史 259/727 ms 尚未再次复现，**不能归因为已经修复的服务端压缩，也不声明尾延迟验收已完全通过**。原因是页面全部 ready 后的切换没有模型/代码请求，服务端压缩发生在 ready 之前；两者不能仅凭先后出现就认定因果。

本轮各页面激活处理约 0.1–1 ms，媒体 src / play 同步调用约 0.1–0.2 ms，播放 Promise 约 4–6 ms。在激活窗口没有记录到超过 3 ms 的同步 WebGL 调用或长任务。启动期间仍有约 250–314 ms 的长任务，基线和修复版均存在；它们发生在 ready 前。本轮没有证据将历史尾延迟归因到具体 JS 解析、GPU 编译或浏览器调度，且没有清除系统级 GPU/驱动缓存。机器负载记录仍有其他 Node 和 WindowServer 活动，尽管性能锁内没有其他任务的性能测量。
