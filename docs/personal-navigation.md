# 个人版页面往返性能

## 目标与实现

本机预备完成后，首页、涂装台和组装台之间点击切换的中位耗时小于 100 ms，保留现有界面、画质、配色、撤销记录和组装进度。

个人版的数据在本地，但原来的每次链接跳转仍会销毁整个页面和 GPU 场景。再次进入需要重取模型、解析几何和准备着色器。组装提示按需计算后，这部分重复工作仍然存在。

现在个人版的三个公共入口使用同一个轻量页面容器，最多保留三个同源文档。先显示当前页面，再在空闲时顺序准备另两页；切换复用现有场景。离开的页面暂停绘制、动画时钟和声音。再次进入组装台时同步草稿的颜色和材质，返回涂装台则保留操作状态。新草稿和配色导入仍执行原有的数据保护逻辑。

地址和前进、后退保持原来的路径。服务器版不启用这个容器。原始 HTML 仍可独立访问，也作为初始化失败时的恢复入口。容器和生命周期模块不增加可见控件或改变样式。

## 实测

2026-10-24，本机 macOS，Playwright 1.58.2 管理的 Chromium 145.0.7632.6，1440×1000、默认画质。基线为 `8fcf150`，候选为本变更。两个隔离的个人版服务使用同一份测试方案数据库、同一套本地模型；基线和候选依次运行，没有并行跑 CPU 测试。

每版创建三个新浏览器上下文，每个上下文完成两轮四条往返路线。指标从真实点击事件开始，到目标页面可操作并经过两次动画帧回调。下表是每条路线六次测量的中位数。候选在首页完成空闲准备后再点击；这是准备后的切换指标，不是全冷启动承诺。

| 路线 | 基线 | 本变更 |
| --- | ---: | ---: |
| 首页 → 涂装台 | 566.5 ms | 28.5 ms |
| 涂装台 → 首页 | 121.4 ms | 28.6 ms |
| 首页 → 组装台 | 718.2 ms | 28.4 ms |
| 组装台 → 首页 | 160.2 ms | 25.7 ms |

本组 24 次切换的最大值为 47.1 ms。首次首页从 113.5 ms 增至 150.4 ms，额外成本来自容器初始化。候选从打开到三页全部准备完成的中位数为 1.47 秒；如果在准备完成前立即点击，仍需等待该页首次初始化。重启页面也需重新准备。不同设备、GPU 或浏览器可能有不同结果。

## 验收证据

| 条件 | 证据 |
| --- | --- |
| 准备后的四条路线中位耗时均小于 100 ms | 本机 25.7–28.6 ms |
| 往返不重复创建文档或加载模型 | 五轮两台往返后仍为三个文档，同一实例标记，无新增模型请求 |
| 隐藏页面不继续消耗绘制或播放声音 | 浏览器记录两台隐藏前后 GPU 绘制计数不变，组装背景音乐暂停 |
| 保留状态且同步配色 | 检查涂装颜色、撤销、相机和步骤；检查组装暂停进度；读取真实场景材质核对修改和撤销后的颜色 |
| 新草稿不丢工作 | 经正常 UI 新开一只，旧草稿备份数增加一，颜色和撤销栈正确重置 |
| 地址及偏好保持 | 直接打开两台、浏览器前进后退、快速连续跳转、跨文档语言同步通过 |
| 视觉保持 | 同尺寸组装整页像素差为零；涂装三维区域像素差为零。涂装整页的随机骰子和进入动画未固定，不作整页一致声明 |
| 小屏幕与实际内置浏览器可用 | 管理 Chromium 390×844 的两台直达、返回和后退通过；Codex 内置浏览器首页与两台往返可操作 |

Node：224 项通过，3 项因未生成可选压缩资产而跳过。完整 Python：60 项通过，18 项 MySQL 检查因未配置测试库而跳过。系统 Python 个人版 11 项通过。组装浏览器回归仍只解析访问的第 0、110 步。

这些是技术检查。用户对“无感”的实际体验仍需在本机点击判断。

## 复测

浏览器导航回归通过正常 UI 创建一条草稿备份，应使用隔离的测试数据库。先导入本地资产，再启动测试服务：

```sh
DUCK_PERSONAL_DB=/tmp/letsduck-navigation-test.db python3 run.py --port 8897 --no-open
```

```sh
npm ci
DUCK_BROWSER_URL=http://127.0.0.1:8897 node tests/personal-navigation-browser.js
DUCK_BROWSER_URL=http://127.0.0.1:8897 node tests/assembly-loading-browser.js
node --test tests/*.mjs tests/assembly/*.mjs
python3 -m unittest discover -s tests -p test_personal.py -v
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/publication_audit.py
```

浏览器回归的截图和计时保存在被忽略的 `output/playwright/personal-navigation/`。本机对比的原始记录另存于项目上下文的验证目录，不随源码发布。
