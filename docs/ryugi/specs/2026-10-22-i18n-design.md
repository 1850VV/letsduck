# 涂鸭 12 语言 · 设计 v1

状态：**用户已确认 v1 的入口、12 种语言、完整翻译范围与自动规则；已接入，技术检查完成，正式页面视觉验收待用户确认。**

用户要求整个工作台支持主流语言、有常驻语言切换入口，并尽量自动选择语言。2026-10-22 用户已选择 12 种：简体中文、繁體中文、English、Français、Español、Русский、العربية、日本語、한국어、Deutsch、Português、हिन्दी。葡语采用巴西葡语，是本方案的默认取舍。

## 看得到的变化

1. 涂装台和配色广场右上角常驻「◎ 当前语言 ⌄」，与登录入口相邻；窄屏保留语言入口。阿拉伯语随界面从右向左镜像到左侧。
2. 菜单提供「自动选择」和全部 12 种语言，每种语言用自己的文字显示名称，不以国旗代替语言。当前模式有勾选标记。
3. 第一次访问读取浏览器偏好语言，按偏好顺序匹配；简体/繁体根据语言地区区分，葡语统一映射巴西葡语。没有支持的匹配时显示英语。
4. 手动选择立即更新界面，并在本浏览器记住；页面跳转、刷新后保留。显式选择优先于自动检测；点「自动选择」清除手动覆盖。语言设置不要求登录，不做跨设备同步。
5. 切换时保留草稿、当前步骤、选区、锁定、颜色、撤销记录、模型视角和登录状态。若有打开的编辑弹窗，保留输入内容。无需重新载入模型。
6. 阿拉伯语采用从右向左的界面阅读顺序；真实模型和空间操作保持原有方向。HEX、耗材编号和配色码保持从左向右，用户昵称/标题使用自动文字方向。长译文正常换行或展开，避免截掉主按钮。

## 完整翻译范围

覆盖运行时实际可见的界面：三步涂装、工具与部位名、内置配色与动作描述、耗材颜色的显示名、配色广场和作品详情、登录注册与账号资料、私有方案、评分、发布、确认弹窗、空状态、加载状态、错误/成功通知、工具提示、无障碍标签、分享海报固定文案、BOM/导出审核的可读标签与警告、相对时间和数量表达。

用户自己写的方案名、作品标题/描述、昵称不自动翻译。产品品牌、材料牌号、型号、SKU、HEX、零件 ID、分享码、资产哈希与制造数据保持原值。原始 3MF 内对象名、网格、工艺和材料参数不因切换语言而重写；显示层提供翻译名，BOM 可读列名随界面语言。README 等开发文档不在这一轮的产品翻译范围内。

## 自动语言与 IP

推荐本轮采用：**已保存的手动选择 → 浏览器偏好列表 → 英语**。浏览器主动提供偏好语言，适合本地与公网部署；运行时不调用外部翻译或定位服务，不增加付费依赖。

IP 可以辅助猜测地区，但本地服务只看到回环地址，代理出口也不代表用户语言。本轮不把 IP 定位列为已实现或验收条件。未来公网部署可接可信代理的地区信息作为无语言匹配时的兜底；不直接信任客户端自报的国家请求头。用户已明确确认本轮不做 IP 定位。

## 实现约束与测试

正式源码基线为 `public-release/duck-palette` 的 `ae2a606`。实现位于隔离工作树的 `codex/i18n-12` 分支，并同步保留最新主线 `698db55` 的手机广场和作品二维码功能。本地入口仍为 `http://127.0.0.1:8876/`，数据库继续使用原位置，资产内容保持不变。

- 沿用无构建的原生 ES modules 和 Python 标准库；小型键值字典集中管理，12 种语言的键与占位符一致。界面显示使用翻译函数，不用全页搜索替换，也不扫描和改写用户文本。
- 将用中文字符串参与逻辑判断的地方改为稳定 ID/错误码；API 错误提供稳定 code 与 params，前端根据当前语言显示提示，兼容已有 error 字段。部位/耗材翻译映射到稳定 ID，不更改源资产。
- 运行 README 的 Python 全量测试、Node 全量测试和 publication audit；补充语言选择、偏好保存、键/占位符覆盖、错误码、未支持语言回退等有意义的测试。
- 实际浏览器验收覆盖 12 种语言、桌面与窄屏、菜单键盘操作、跨页面/刷新记忆、草稿与视角不丢失；重点检查德语/俄语长文案及阿拉伯语排版。
- 对登录错误、保存、广场、海报/BOM和导出警告检查翻译。导出回归仍验证制造数据不变。机器翻译审校与母语质量验收分别报告；当前没有完成母语人工审校。
