# 公开发行范围与检查

仓库包含来做鸭的应用源码、构建程序、测试、文档、保留原许可的第三方代码，以及项目运行与打包所需的 `assets/`。客户端使用随包资源；从仓库构建也无需另外寻找素材。

## 项目资源

`assets/` 收录固定 3MF、模型与几何、色库、打印预设、导出描述及组装预览媒体。资源按原有来源与独立条款提供，代码的 MIT 许可证不改变这些条款；见[第三方声明](../THIRD_PARTY_NOTICES.md)和[项目资源](local-assets.md)。

发布检查放行指定的根资源文件及 `scripts/assembly-assets.json` 已列明的组装资源，继续拒绝未列入清单的二进制、软链接、私人路径和凭据。资源字节通过 `.gitattributes` 保持不受平台换行转换影响。

## 不纳入仓库的内容

- 用户数据库、命名方案、浏览器存储、个人 profile 与真实设备记录。
- 私人聊天、账户与插件配置、令牌、密钥、环境变量文件。
- 开发机绝对路径、预览访问密钥、私有会话链接。
- 未审阅的替代模型、用户导出、安装包、日志、缓存与临时交付目录。

逐项审阅并暂存所需文件，不把整个私人工作目录直接推送。公开提交使用 GitHub no-reply 身份。

## 验证范围

执行根 README 和[开发说明](development.md)中的适用检查。源码检查、完整模型检查、安装包、浏览器包、人工体验、实际打印与真实设备各自报告；资源存在或 CI 通过不代表全部产品验收通过。

README 截图与动图放在 `docs/media/`，单文件不超过 3 MB，使用示例数据。供应商文件保留原始字节与许可，资产保留来源和媒体署名。发布审计是启发式检查，不能代替实际差异审阅。
