# 公开发行范围与检查

日期：2026-10-22。项目名：DuckPalette（鸭子调色台）。发布对象：原创应用源码、测试、文档、可编辑原型源码和保留许可的 Three.js。

## 收录内容

- 当前本地工作台的前端、Python 服务和导出逻辑，包括已确认的专注模式 B 方案。
- 规则与导出测试、实际浏览器检查脚本，以及不依赖模型的本地资产导入测试。
- 完整使用手册、需求、UI 工作流、社区设计、授权与部署研究的脱敏历史副本。
- 早期模型检查和报表生成脚本；明确标为历史工具，并说明其缺失输入与未验证的重建流程。
- MIT LICENSE、第三方声明、贡献指南、安全报告说明与公开源码 CI。

## 保留在本地的内容

| 类别 | 原因 |
| --- | --- |
| 原始与改色 3MF、STL、几何二进制、模型清单、打印参数中间文件 | 不能用原创软件 MIT 覆盖模型和制造数据的独立条款 |
| 耗材目录及导出描述快照、上游源码表 | 未确认可按 MIT 再分发；保留上游来源说明 |
| 模型图片、渲染图、录像、PDF、压缩包和交付归档 | 可能包含同一受限模型及历史元数据，未纳入本次公开分发 |
| 私人聊天全文、浏览器存储、自动化会话、缓存、临时日志 | 不属于公开产品源码，且可能包含私人信息 |
| 机器上的绝对路径、用户目录名、预览访问密钥、会话链接 | 文档副本脱敏，原始私人文件不上传 |
| 本机插件配置、账户配置、凭据、环境变量文件 | 不复制到公开仓库 |

原始私人项目没有被删除、移动或覆盖。公开目录是一份可审计的发行副本，当前本机已运行服务与它独立。后续发布也必须审阅差异，不能把整个私人目录直接推送。

## 技术检查

- 带本地资产：12 项 Python 测试（含 8 项导出测试与 4 项导入测试）、29 项 Node 规则测试通过。
- 公开副本通过实际本机浏览器的 24 项专注模式检查；模型资产只出现在该本地测试目录中。
- 8 个生产 JavaScript 模块语法检查通过。
- 无资产启动会明确提示五个缺失文件；不会冒充可直接运行的完整模型发行版。
- 暂存内容经过路径、私密链接、凭据模式、二进制与受限文件检查，并人工复核邮箱及内嵌图片引用。保留的邮箱为上游公开联系地址；内嵌 SVG 是界面图标，测试 PNG 是程序生成的占位数据。
- Gitleaks 8.30.1 扫描待发布的完整文件快照，未发现匹配的密钥泄漏；这不替代人工审查。
- 提交使用 GitHub no-reply 邮箱，不使用本机私人邮箱。使用新的发行提交，不推送私人工作目录的历史。

这些是有范围的技术检查，不是“保证不存在任何隐私问题”的声明。公开 CI 只运行不依赖受限资产的检查；实际打印、切片器往返、多用户后端和用户视觉验收不在本次发布检查内。

Three.js 保持原始文件内容，其原有空白格式不做重排；`.gitattributes` 仅排除供应商文件的空白告警，项目自己的文件仍检查。

## 3.0 更新（涂鸭 DoodleDuck，前后端分离）

- 旧工作台、社区演示与 A/B 原型移除，涂装台 v2 与配色广场成为唯一入口（`frontend/`）；后端拆到 `backend/`，新增 SQLite 账号、方案、作品与评分存储和 Docker 部署文件。

- 上面「技术检查」一节记录的是首次发行；本次的检查结果写在对应提交说明里。
