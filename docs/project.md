# 项目结构与工作流

DuckPalette 专注 XGO Duck V2 的配色及模型展示，尚不支持任意机器人或任意 3MF 导入。

| 入口 | 职责 |
| --- | --- |
| `run.py` / `start.py` | 本地启动、静态资源、校验与 3MF 导出接口 |
| `app.js` | Three.js 场景、方案、耗材绑定及功能集成 |
| `focus-workspace.mjs` | 单视窗整机/部件、联动旋转、模式视角记忆、浮动色盘 |
| `color-workflows.mjs` | 项目色盘、连续点涂、就近调色、命名保存 |
| `duck-workbench.mjs` | 专用分区、展示与操作范围 |
| `community-store.mjs` | 本地社区版本、评分和引用规则 |
| `exporter.py` | 固定源 3MF 的材料分配与保留校验 |
| `tests/` | 规则、导出、导入及浏览器回归 |
| `design/` / `docs/history/` | 可编辑原型源码与脱敏研究记录 |

## 当前边界

- 草稿、命名方案、偏好及社区演示保存在当前浏览器的本机地址下。
- 保存私有方案不等于公开发布；社区演示不是多人服务器。
- 旋转联动和配对上色是两个独立开关；默认只涂当前零件。
- 组装/散开/排列只改变显示变换，不写入打印结构。
- 原模型中合并的双眼等部件不能凭 UI 分成独立可制造零件。
- 软质件沿用 TPU 90A；不擅自改成 95A。
- 未接入 MCP、账户系统、支付、自动切片或打印机控制。

## 开发流程

UI 改动先提供可点击原型，确认具体版本后再改实际应用。实现后用真实页面截图、必要的操作录像和相关测试验收。内部实现、文档与配置按其风险验证，无需为此制造新的 UI 审批。

本次公开发行保留已经确认的 B 方案。`docs/verification/focus-b.json` 记录的是本地检查，不代表用户已完成视觉验收。历史文档中的“待确认”“当前目录”等描述属于当时上下文，以根目录 README 和此文为当前公开版本入口。
