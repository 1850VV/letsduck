# 界面翻译

语言入口同时出现在涂装台和配色广场。语言优先级是当前浏览器保存的 `dd-locale`、`navigator.languages` 中第一个支持的语言、英语。选择“自动选择”会删除手动覆盖。繁体地区和 `zh-Hant` 匹配繁体；其他中文匹配简体，葡语匹配 `pt-BR`。不使用 IP 定位，不要求登录，不跨设备同步设置。

`frontend/shared/i18n.mjs` 管理语言、参数、日期和数字格式；`language-menu.mjs` 提供入口。静态字典在 `frontend/locales/catalogs.mjs`，表单验证补充在 `extra.mjs`。`source-keys.mjs` 只映射内置部位、耗材和系统标签。新增文案须为全部语言提供相同键和占位符，不要把用户昵称、标题或描述传给 `label()`，也不要扫描整页替换文字。API 使用稳定 `code` 和 `params`；保留旧 `error` 字段兼容调用方。

译文在开发阶段用 Microsoft Translator 网页生成候选，并对原型文案、品牌名和部分英语术语做了人工校正。字典随源码提供，运行时没有翻译服务请求或第三方依赖。当前尚未完成全部语言的母语人工审校；键、占位符和界面覆盖检查不能代替译文质量审校。

切换语言只更新显示层。零件 ID、耗材 ID、几何、制造参数、原始 3MF 名称保持不变。切换时保留当前步骤、草稿、选择、锁定、撤销和模型视角。阿拉伯语更新页面阅读方向，WebGL 相机和空间方向保持原样。

完整验证使用 README 中的 Python、Node 和 publication audit 命令。`test_i18n*.mjs` 检查偏好、占位符、未译中文和稳定部位判断；`test_api_i18n.py` 检查 HTTP 错误码和用户原文保存。浏览器脚本 `tests/i18n-*.js` 供任务专用 Playwright 会话的 `run-code --filename=…` 使用，默认目标为临时数据库服务 `127.0.0.1:8877`；不要对已有用户数据库运行注册/保存验收。浏览器脚本覆盖桌面、手机、全部语言、视角、原生表单提示、海报和导出页面。
