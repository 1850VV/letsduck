# 界面翻译

首页、涂装台、调试台、组装教程和配色广场使用同一语言偏好。语言优先级是当前浏览器保存的 `dd-locale`、`navigator.languages` 中第一个支持的语言、英语。选择“自动选择”会删除手动覆盖。繁体地区和 `zh-Hant` 匹配繁体；其他中文匹配简体，葡语匹配 `pt-BR`。同源窗口监听 storage 变化，只重读已有偏好；桌面自有菜单由可信主窗口同步到内存，不再保存第二份设置。不使用 IP 定位，不要求登录，不跨设备同步设置。

`frontend/shared/i18n.ts` 管理语言、参数、日期和数字格式；`language-menu.ts` 提供入口。静态字典在 `frontend/locales/catalogs.ts`，表单验证补充在 `extra.ts`。`source-keys.ts` 只映射内置部位、耗材和系统标签。新增文案须为全部语言提供相同键和占位符，不要把用户昵称、标题或描述传给 `label()`，也不要扫描整页替换文字。API 使用稳定 `code` 和 `params`；保留旧 `error` 字段兼容调用方。

首页名称与品牌在 `identity.ts`；Debug、Assembly 和设备系统消息分别在对应静态字典中，由功能入口加载。首页不导入功能页的大字典。Assembly 用稳定步骤/部件 ID 与字段取显示副本，不改写教程、几何或制造数据。

初版译文在开发阶段用 Microsoft Translator 生成；补充文案使用开发阶段候选工具及显式静态翻译，修正品牌和关键术语。候选必须保留全部键及占位符，失败批不并入。字典随源码提供，运行时没有翻译服务请求或第三方依赖。当前尚未完成全部语言的母语人工审校；键、占位符和界面覆盖检查不能代替译文质量审校。

设备控制器保留原错误文字、现有 `code`/`params` 和协议行为，为已知系统消息附加可选描述符。HTTP 的 `messageCode`/`messageParams`、状态的 `errorCode`/`errorParams`、记录的 `reviewReasonCode`/`reviewReasonParams` 在功能页渲染时翻译。未知设备诊断保留原文。桌面启动前的错误按系统语言回退；系统自有对话框由操作系统控制。

切换语言只更新显示层。零件 ID、耗材 ID、几何、制造参数、原始 3MF 名称保持不变。切换时保留当前步骤、草稿、选择、锁定、撤销和模型视角。阿拉伯语更新页面阅读方向，WebGL 相机和空间方向保持原样。

完整验证使用 README 中的 TypeScript、Node 和 publication audit 命令。`test_i18n*.ts` 检查偏好、占位符、未译中文和稳定部位判断；`tooling/test/server-routes.test.ts` 与冻结 HTTP oracle 检查 HTTP 错误码和用户原文保存。浏览器片段 `tests/i18n-*.ts` 通过 `npx tsx tests/browser/run-check.ts --fixture community --check CHECK.ts` 执行，runner 拥有独立端口与临时库；不要对已有用户数据库运行注册/保存验收。浏览器脚本覆盖桌面、手机、全部语言、视角、原生表单提示、海报和导出页面。
